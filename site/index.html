SIS Login Fix

Browser extension and userscript for Charles University SIS (is.cuni.cz/studium/), WebApps (is.cuni.cz/webapps/), and CAS (cas.cuni.cz/cas/). Fixes missing and expired session tokens in SIS links and makes the CAS 2FA code field autofill properly.

Install

  • Firefox Add-ons
  • Chrome Web Store
  • Userscript (sis-login-fix.user.js)
  • GitHub Releases (v1.0.0)

Use the extension or the userscript, not both in the same browser profile. Session state stays in is.cuni.cz site storage and nothing leaves your browser.
